# Sentra Redesign Reference Notes

## Public references reviewed

The redesign research considered [Awwwards’ interactive collection](https://www.awwwards.com/websites/web-interactive/), [Awwwards’ white-site collection](https://www.awwwards.com/websites/white/), [SiteInspire’s editorial collection](https://www.siteinspire.com/websites/category/editorial), [Squarespace Foundations](https://brand.squarespace.com/), and Tubik’s editorial design analysis. These are references for design principles only; Sentra will not reproduce any individual site’s visual identity or layout.

## Transferable principles

| Reference pattern | Sentra interpretation |
| --- | --- |
| Light sites use whitespace to create focus, contrast, and perceived quality. | Use a warm off-white field, large asymmetrical margins, and one dominant interactive artifact instead of dense cards. |
| Editorial systems let typography set rhythm before decoration. | Make the core claim typographic and use a sharp visual hierarchy with compact system captions. |
| Strong interactive sites make motion explain the product rather than decorate it. | Animate only the authority handoff: proposal, policy decision, capability, gateway, and proof. |
| Identity systems use a few repeatable visual primitives. | Establish a Sentra “authority ribbon”: connected proofs, clipped status stamps, and a rotating capability seal. |
| Premium interfaces use material contrast rather than dark gradients. | Use porcelain surfaces, ink-like typography, translucent paper overlays, fine hairlines, and restrained oxblood as the authority accent. |

## Explicit exclusions

The redesign will avoid generic dark cyberpunk panels, neon glows, glass-card grids, auto-generated dashboard aesthetics, over-rounded components, decorative particle fields, gradient overload, and motion that does not explain an authority decision.
